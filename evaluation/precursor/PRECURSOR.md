# Precursor evaluation (6-day dataset)

Generated by `evaluation/precursor/precursor_eval.py`; every number is in `precursor_results.json`.
(6-day dataset) the 10-day rebuild did not pass its check (fix/restore-10day-dataset, REBUILD_CHECK.json); these predictions are on the 6-day e200fdb dataset the models were trained on.

A precursor window has no attack yet (label_binary = 0) but an attack within the next 5 minutes
(future_attack_label = 1). In the dataset 984 windows are onset-positive: 913
are already inside an attack and only 71 are precursors. The LOEO test set (412 windows) holds
15 precursors, 248 benign non-precursor windows and 149 in-progress attack windows.

Scored on precursors vs benign non-precursor windows only, using the committed LOEO test predictions
