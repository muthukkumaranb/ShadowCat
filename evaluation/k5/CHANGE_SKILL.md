## Summary of Change-Window Performance

A **change window** is defined as any test window where $y(t+K) \neq y(t)$ (attack onset $0 \to 1$ or attack offset $1 \to 0$).
Persistence always predicts the preceding state, so change windows are where a forward simulation can add
information beyond it. Evaluating on change windows isolates that question.
